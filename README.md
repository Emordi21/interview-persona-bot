# AI Interview Agent

A chatbot that helps you prepare for AI roles: **AI Product Manager**, **Forward Deployed Engineer**, **AI Researcher** and **Agile Business Analyst**.
Pick a role, then either **chat** with a role-specific coach or take a **quiz** (5 multiple-choice questions generated by Gemini, with instant feedback, explanations and a review screen).

## Run it

```bash
npm install
npm run dev
```

Open the printed URL, paste your Gemini API key (free from https://aistudio.google.com/apikey) and start chatting.
The key is kept in `sessionStorage` (cleared when the tab closes) and only sent to Google.

## Project layout

| File | What it does |
| --- | --- |
| `index.html` | Page structure: title, job buttons, chat, API key popup |
| `src/personas.js` | The 4 roles: system prompts, quiz topics, colours, greetings |
| `src/gemini.js` | Calls the Gemini API for chat and quiz generation (model name lives in `MODEL`) |
| `src/main.js` | App logic: role switching, chat, quiz, per-role history |
| `src/style.css` | Blue/neon grid theme and per-job colour transitions |

## Notes
- The model is set to `gemini-3.8-flash` in `src/gemini.js`. If Google returns "model not found", change that one constant.
- The key is used directly from the browser, which is fine for personal use. For a public deployment, move the API call to a small backend so the key is never exposed.
